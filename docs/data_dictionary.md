# Branches Table

| Column | Data Type | Description |
|----------|------------|-------------|
| branch_id | String | Unique identifier assigned to each warehouse branch |
| branch_name | String | Name of the warehouse branch |
| city | String | City where the branch is located |
| state | String | State where the branch operates |
| region | String | Geographic region of the branch |
| warehouse_type | String | Classification of warehouse facility |
| warehouse_capacity | Integer | Maximum storage capacity of the warehouse |
| service_center_available | Integer | Indicates whether a service center is available (1 = Yes, 0 = No) |
| manager_id | Integer | Unique identifier of the branch manager |
| total_employees | Integer | Total number of employees working at the branch |
| avg_monthly_revenue | Integer | Average monthly revenue generated by the branch |
| monthly_operational_cost | Integer | Average monthly operating cost of the branch |
| market_demand_index | Integer | Demand score representing market demand in the branch area |
| revenue_per_sqft | Float | Revenue generated per square foot of warehouse space |
| cost_revenue_ratio | Float | Ratio of operational cost to revenue generated |
